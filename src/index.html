使用帮助

快速上手

  1. 导入素材 — 支持 MP4 / MOV / WebM / MKV 视频、常见图片、MP3 / WAV / M4A 音频与 TXT 文本。
  2. 编排轨道 — 点击素材「+」加入时间轴，拖动片段移动，拖动两端进行裁剪。
  3. 叠加内容 — 文本、图片、字幕拥有独立的入场 / 出场动画与样式设置；字幕支持滚动上移、逐行显示、静态多行与跑马灯四种呈现方式。
  4. 录屏 — 点击右上角「录屏」，最长可录制 1 小时；按 Esc 结束，录屏会自动导入视频轨。
  5. 扩展屏播放 — 点击「扩展屏」即在副屏播放，再次点击停止，再点击继续播放；主屏可继续编辑，修改实时同步。
  6. 导出 — 右上角「导出视频」，自动优先输出 MP4，否则回退 WebM。
